## 2. Deskripsi Proyek
Proyek ini merupakan sebuah website profil dan katalog layanan barbershop dinamis berbasis PHP native tanpa mengikutsertakan framework maupun database. Website ini menyajikan informasi profil usaha barbershop serta katalog pilihan paket perawatan rambut dan grooming yang dilengkapi dengan ringkasan data statistik dan fitur pengurutan (sorting) harga/nama secara interaktif.
